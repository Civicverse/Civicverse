# 🎮 Civicverse: Unreal Engine 5 Shards

## 🚀 Overview
The `/Ue5_project` directory contains the high-fidelity 3D assets and world shards for the Civicverse metaverse. While the **Foyer** is built in Godot for lightweight web access, the **UE5 Shards** represent the premium, ultra-high-fidelity exploration and combat zones of the ecosystem.

### 🎯 Key Objectives
- **Hyper-Realistic Visuals:** Leveraging Nanite and Lumen for cutting-edge metaverse aesthetics.
- **World Sharding:** Creating modular, additive scenes that can be streamed or downloaded as high-fidelity extensions of the Foyer.
- **Combat & Movement:** Developing advanced character controllers and physics-based interactions.

---

## 🏗 Technology Stack
- **Engine:** Unreal Engine 5.4+
- **Rendering:** Nanite, Lumen, Virtual Shadow Maps.
- **Scripting:** C++ and Blueprints.
- **Interoperability:** Modular shards exported as pak files or bridged via the Civicverse Relay.

---

## 🛠 Getting Started

### Prerequisites
- **Unreal Engine 5.4 or later.**
- **Windows or Linux** with high-end GPU (Ray Tracing recommended).

### Setup
1. Open the `Civicverse.uproject` file in the Unreal Editor.
2. Build the project to generate required binaries.
3. Explore the `/Maps/Shards` directory for existing world segments.

---

## 🤝 Contribution
Contributors to the UE5 project should focus on optimization and modularity. Ensure all assets use the Nanite workflow where appropriate and that shaders align with the "Neon Reign" aesthetic (high contrast, emissive neon, bold silhouettes).
